# CEYLON EXPLORER – Tourism Management System

CEYLON EXPLORER is a web-based tourism management platform designed to simplify travel planning in Sri Lanka. The system integrates multiple tourism services such as activity booking, accommodation reservations, vehicle rentals, tourist guides, and itinerary planning into a single centralized platform.

This project is developed as part of the **IT2150 IT Project (SLIIT)**.

---

## Project Overview

Sri Lanka's tourism industry lacks a unified digital platform that integrates essential travel services. Tourists often have to use multiple websites and platforms to book hotels, arrange transportation, hire guides, and plan activities.

CEYLON EXPLORER solves this problem by providing a centralized tourism management system where users can easily browse, plan, and book their travel services in one place.

---

## Key Features

- Activity & Experience Booking
- Hotel & Accommodation Booking
- Vehicle Rental Management
- Tourist Guide & Driver Selection
- Healthcare & Emergency Services Information
- Travel Itinerary Builder
- Location-based Tourism Information
- Reviews and Ratings
- Admin Dashboard for Service Management

---

## Activity Booking System

The Activity Booking module allows users to:

- Browse available tourist activities
- View activity details including price, duration, and location
- Filter activities by category and difficulty level
- Check seasonal availability
- View safety guidelines and restrictions
- Book activities online
- Receive booking confirmations
